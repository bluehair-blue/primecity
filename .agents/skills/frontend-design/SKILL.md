# 프론트엔드 디자인 가이드라인

이 프로젝트의 모든 프론트엔드 작업에 적용되는 하드 규칙.
기존 디자인 시스템(다크+골드, OKLCH, 시네마틱 톤)을 유지하면서 고품질 구성을 보장한다.

## 페이지 구성

- **원 컴포지션**: 첫 뷰포트는 하나의 구성으로 읽혀야 한다. 대시보드가 아닌 이상 대시보드처럼 보이면 안 됨.
- **원 잡 퍼 섹션**: 각 섹션은 하나의 목적, 하나의 헤드라인, 보통 하나의 짧은 보충 문장.
- **히어로 버짓**: 첫 뷰포트에는 브랜드, 헤드라인 하나, 짧은 보충 문장 하나, CTA 그룹 하나, 메인 비주얼 하나만. 통계, 일정, 메타데이터, 부가 콘텐츠 금지.
- **클러터 감소**: 필 클러스터, 통계 스트립, 아이콘 나열, 박스형 프로모, 경쟁하는 텍스트 블록 지양.

## 히어로 & 비주얼

- **풀블리드 히어로**: 랜딩/프로모 페이지에서 히어로 이미지는 기본적으로 엣지 투 엣지 풀블리드. 인셋 이미지, 사이드 패널 이미지, 둥근 미디어 카드, 콜라주, 플로팅 이미지 블록 금지.
- **히어로 오버레이 금지**: 히어로 미디어 위에 분리된 라벨, 플로팅 뱃지, 프로모 스티커, 정보 칩 배치 금지.
- **실제 비주얼 앵커**: 이미지는 제품, 장소, 분위기, 맥락을 보여줘야 함. 장식적 그라디언트나 추상 배경은 메인 비주얼로 인정하지 않음.

## 카드 & 컨테이너

- **기본값: 카드 없음**: 히어로에서 카드 절대 금지. 카드는 사용자 인터랙션의 컨테이너일 때만 허용.
- **카드 필요성 테스트**: 보더, 그림자, 배경, 둥글기를 제거해도 인터랙션이나 이해에 문제가 없다면 카드일 필요 없음.

## 타이포그래피 & 브랜딩

- **브랜드 우선**: 브랜드명은 히어로급 시그널이어야 함. 네비바 텍스트나 아이브로우에 그치면 안 됨.
- **브랜드 테스트**: 네비를 제거했을 때 첫 뷰포트가 다른 브랜드에 속할 수 있다면 브랜딩이 약한 것.
- **이 프로젝트 폰트**: `--f-display-kr` (Noto Serif KR), `--f-display-en` (Crimson Pro), `--f-body` (Noto Sans KR). 기본 스택(Inter, Roboto, Arial) 사용 금지.

## 배경 & 분위기

- **플랫 배경 금지**: 단일 색상 플랫 배경에 의존하지 않음. 그라디언트, 이미지, 서틀 패턴으로 분위기 구축.
- **이 프로젝트**: `C.bgDeep` 기반 + Particles 배경 + 비네팅 그라디언트 조합 유지.

## 모션

- **의도적 모션**: 시각적 작업에 최소 2~3개의 의도적 모션 사용. 존재감과 위계를 만드는 용도, 노이즈가 아님.
- **이 프로젝트 이징**: `cubic-bezier(0.22, 1, 0.36, 1)` 통일.
- **스크롤 트리거**: `useReveal` 훅 기반 IntersectionObserver.
- **전역 keyframes**: `index.html`의 `<style>` 태그에 정의 (컴포넌트 내 `<style>` 삽입 금지).

## 반응형

- **데스크톱/모바일 모두 정상 로드 보장**.
- **이 프로젝트**: `useIsMobile(768)` 훅으로 분기. 모바일은 성능 최적화 최우선 (will-change, GPU 가속, filter/blur 축소).

## 색상

- **이 프로젝트**: OKLCH 전용. hex/rgb/hsl 금지. `src/styles/tokens.js` 토큰 사용.
- **투명도 적용**: `color-mix(in oklch, color N%, transparent)` 패턴 사용 (`.replace()` 금지).

## React 패턴

- **함수형 컴포넌트 + Hooks** (클래스 컴포넌트 금지).
- **`function` 키워드**로 컴포넌트 선언 (`const` 화살표 함수 X).
- **useMemo/useCallback**: 기존 코드에서 사용하지 않는 한 기본 추가하지 않음.
- **useEffect 의존성 배열**: 반드시 명시. 누락 금지.
- **setTimeout**: `useRef`로 관리하여 race condition 방지.

## 예외

기존 디자인 시스템과 시각적 언어가 확립된 페이지에서 작업할 때는, 확립된 패턴/구조/비주얼 언어를 보존할 것.
