> **에덴챗 로어북 메커니즘 정확 이해 후 작성**
> v1, v2 모두 폐기. 이 문서가 정식 가이드.

## 🎯 핵심 원칙 (재정립)

### 1. 로어북 활성 메커니즘
```
[메인 프롬프트] (항상 활성)
        +
[트리거 매칭된 로어북] (필요할 때만 동적 편입)
        ↓
[현재 턴의 컨텍스트]
```

- 모든 로어북이 한 번에 합쳐지지 않음
- 트리거 키워드가 매칭될 때만 해당 로어북이 컨텍스트에 추가
- 따라서 **로어북 분리 = 정확한 활성 = 컨텍스트 효율**

### 2. 통합이 잘못된 이유
- **컨텍스트 비용 증가**: 통합된 큰 로어북이 더 자주, 더 광범위하게 활성됨
- **트리거 정밀성 손실**: 통합 시 트리거가 광범위해져서 무관한 상황에서도 활성
- **AI 혼동**: 여러 시스템(예: 9개 SVG 워커)의 규칙을 하나로 묶으면 AI가 적용 대상 헷갈림

### 3. 올바른 방향
| ❌ 하지 말 것 | ✅ 해야 할 것 |
|-------------|--------------|
| 로어북 통합 | 로어북 추가 (세분화) |
| 내용 축약 | 내용 구체화 (디렉션 강화) |
| 트리거 광범화 | 트리거 정밀화 |
| SVG url_rules 통합 | 각 SVG 활용 시나리오 보강 |

## 🔑 트리거 키워드 설계 원칙

### 핵심 철학

**트리거 설계 = AI 대화 시뮬레이션**

"이 로어북이 활성되어야 할 상황에서, 유저 or AI가 실제로 어떤 단어를 사용할까?"를 예측하는 작업. 좁으면 누락, 광범위하면 오활성. 정밀도가 생명.

### 6가지 트리거 유형 (모두 병행)

| 유형 | 설명 | 예시 (한소리_트리거) |
|------|------|----------------------|
| **1. 표면 키워드** | 유저 메시지에 직접 등장할 단어 | `포기`, `실망`, `적자` |
| **2. AI 응답 예측** | AI가 캐릭터 묘사 시 사용할 단어 | `후배님`, `어떻게든`, `실눈`, `다크서클` |
| **3. 상황 맥락** | 해당 상황이 전개되면 자연스레 나오는 단어 | `마지막`, `접힘`, `기획사가` |
| **4. 시각 시그니처** | 캐릭터 고유 묘사 단어 | `실눈`, `다크서클`, `장부`, `월세` |
| **5. 활용형/조사 변형** | 한국어 어미 변형 대응 | `기획사가`(조사), `눈을 뜨`(활용형) |
| **6. 유의어/관련어** | 같은 개념의 다양한 표현 | `포기` / `포기해` / `그만` / `접을` |

### 트리거 작성 체크리스트

새 로어북 작성 시 반드시 확인:

- [ ] **유저 질문 시뮬레이션**: "이 상황이면 유저는 어떤 단어를 쓸까?"
  - 직접 질문 ("과거가 어떻게 돼?")
  - 간접 탐색 ("왜 저래?")
  - 감정 반응 ("포기하자", "괜찮아?")
- [ ] **AI 응답 시뮬레이션**: "이 상황 묘사 시 AI가 어떤 단어를 포함할까?"
  - 캐릭터 시그니처 (외형/습관/소품)
  - 캐릭터 대사에 자주 나올 단어
  - 지문 묘사 (행동/표정)
- [ ] **한국어 활용 대응**: 조사/어미 변형 고려
  - 체언: `기획사`, `기획사가`, `기획사는`, `기획사의`
  - 용언: `포기`, `포기해`, `포기할`, `포기하`
- [ ] **유의어 망**: 같은 개념의 다양한 표현
  - `포기` 계열: 그만, 접어, 끝내, 포기
  - `적자` 계열: 돈, 월세, 빚, 파산, 자금난
- [ ] **오타/오기 대응** (선택): 자주 틀리는 단어
  - 예: `스케줄` / `스케쥴` / `스캐줄` (SVG_일정표 모범 사례)

### ❌ 피해야 할 트리거

| 유형 | 이유 | 예시 |
|------|------|------|
| **너무 일반적** | 무관한 상황에서도 오활성 | `대화`, `이야기`, `시작` |
| **조사 없는 짧은 체언** | 매칭 범위가 너무 넓음 | `일`, `곳`, `때` |
| **메인 프롬프트와 겹침** | 이미 항상 활성이라 의미 없음 | `서윤` (본체 로어북은 예외) |
| **중복 키워드** | 다른 로어북과 경합 | 여러 캐릭터 공통 단어 |
