## 4. sym 섹션 삭제 (연쇄 작업 포함)

### 메인 프롬프트
```json
"sym": "⚙=프로듀서 ∮=싱어송라이터 ∂=작곡 ⚡=래퍼 ✦=아이돌 ✧=모델 ✿=연습생 ◐=인플루언서 ▷=배우 🏢=대표 ⬡=반말 ⬢=존댓말 — 해당 기호는 출력하지 않는다."
```
→ **전체 삭제** (1줄 감소)

### 근거
- chars 축약으로 기호 참조 0건
- 각 모드 로어북에서 필요한 기호(`▷`=배우모드, `📋`=매니저모드 등)는 해당 로어북 내에서 자체 정의 중
- `⬡`/`⬢`(말투)는 메인 외 참조 0건 — 완전 안전

### 연쇄: 플랫폼 캐릭터 프롬프트 풀어쓰기

플랫폼 측에 이관된 캐릭터 프롬프트의 기호를 **모두 단어로 치환**한 텍스트 블록을 별도 파일로 생성 제공:

- 19명 전원 포함

## 10. 리스크 및 롤백

### 잠재 리스크
1. **경량 모델이 새 카테고리명 `로맨스`를 NSFW로 오인** → 카테고리 설명에 "(SFW, 일상 친밀 접촉)" 명시
2. **기호 풀어쓰기 누락 시 플랫폼 프롬프트 AI 오판** → 제공 블록 1:1 검수
3. **terms 용어 풀어쓰기 이관 시 본체 로어북의 톤 불일치** → `inner` 필드에 기존 문장과 자연스럽게 연결

### 롤백 계획
- Git 단일 커밋으로 묶음 → `git revert {hash}` 로 즉시 원복 가능
- `메인_프롬프트_EN.json` + `이미지_NSFW_EN.json` + `에리카_이서하_짠꿉공_EN.json` + 본체 로어북 7개 = 총 10개 파일 수정을 **하나의 커밋**으로 처리
