## 0. 설계 원칙

| 원칙 | 설명 |
|---|---|
| **경량 모델 호환** | 영문 축약형 → 한국어 완전문. 약어·생략 최소화. 단 문장 1개가 1동작을 묘사하도록 단순화 |
| **글자수 검약** | 각 로어북 **15~22줄** 범위. 과도한 디테일은 오디션모드 본체·막간·캐릭터 로어북에 위임 |
| **단계 = 서사 비트** | `flow` 배열의 각 스텝에 "무엇을 묘사해야 하는가" 1줄 명시. 경량 모델이 순서대로 렌더할 수 있도록 |
| **책임 분리 — 최우선** | 라운드 로어북은 **틀(flow)과 연출 가이드(tension)**만 담는다. 심사위원의 평가 성향·톤·개입 패턴은 **오디션모드 본체 `judges`** 및 **각 캐릭터 본체 로어북**이 이미 담당하므로 **중복 서술 금지**. 로어북을 쪼개둔 이유를 지키는 것 |
| **메인 프롬프트 중복 회피** | `absolute_rules`, `scene_roster`, 상태창 fmt 등은 참조만 하고 재정의하지 않음 |
| **본체 위임 영역 존중** | `오디션모드_EN.json`에 이미 있는 `round_flow.transitions`, `slots`, `status_fmt`, `judges`는 재복사하지 않음 |
| **시간 구조 명시** | 각 라운드는 **며칠·언제** 진행되는지 명시. flow 단계마다 시간대(오전·오후·저녁 등)를 병기하여 AI가 상태창 🕐 시간 진행을 자연스럽게 반영 |

## 1. 현재 문제 진단

### 문제 1: 영문 축약 때문에 해석 불안

**예시 — 1R**:
```
"flow": "① MC opening+judge intro+entrance → ② Individual stages → ③ Judge comments → ④ Scoring({{user}} first, then 진시혁/에리카 revealed) → ⑤ All grades finalized."
```

- 한 줄에 5단계 뭉침
- "MC opening+judge intro+entrance" — 3가지 서로 다른 비트를 `+`로 합침
- 경량 모델이 "④ Scoring(...)" 괄호 의미를 놓치면 심사 순서 틀어짐

### 문제 2: 연출 포인트 부재

- "Judge comments" → 누가 어떤 톤으로? 진시혁 혹평? 에리카 호평?
- "Group meeting(free conversation)" → 무엇에 관한 대화? 긴장감은?

현재는 **행위 나열**일 뿐 **연출 가이드**가 없어 AI가 메마르게 재현.

### 문제 3: 감정 구도 부재

현재 각 라운드 로어북에는 "이 라운드의 핵심 긴장이 무엇인가"가 없다. 모든 라운드가 같은 무게로 흘러감 — 팀워크가 칼날로 변하는 3R-B와, 권력이 역전되는 4R의 결이 구분되지 않음. AI가 라운드별 무드를 다르게 연출할 실마리가 필요.

## 2. 구체화 방향 (공통)

각 라운드 로어북의 표준 구조:

```json
{
  "id": N,
  "title": "...",
  "situation": "한 문장 — 현재 참가자 수·권력 구도·직전 라운드 여파",
  "timing": "라운드 총 소요(예: 1일 · 2일) + 직전 라운드와의 공백 기간",
  "flow": [
    "① 단계 이름 (시간대) — 누가 무엇을 하고 어떤 무드로 묘사하는가 (1~2문장)",
    "② ...",
    ...
  ],
  "tension": "이 라운드의 핵심 감정 구도 (1~2문장)",
  "end": "다음 라운드로 넘어가는 조건·태그 전환"
}
```

> **의도적으로 제외**: 심사위원 평가 성향·개입 패턴은 `오디션모드_EN.json`의 `judges`와 각 캐릭터 본체 로어북이 담당. 라운드 로어북은 틀과 무드만.

**구성 요소별 증가분**:

- `flow` 한국어 완전문화 + 각 단계 시간대 병기 — 라운드당 ~6줄
- `situation` + `tension` + `timing` 필드 추가 — 라운드당 ~3줄
- `character_beats` 제거로 라운드당 4~5줄 절감(순상쇄)

**예산 상황**: 메인 프롬프트 최적화로 61줄 절감 → 이번 54줄 재투자 = 순 **-7줄** 여전히 균형.
