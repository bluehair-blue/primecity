## 0. 설계 원칙

| 원칙 | 설명 |
|---|---|
| **느낌표는 방어벽** | `!모드명` 접두사는 일반 대화 중 오발동을 막는 핵심 안전장치. 오디션 모드를 제외한 모든 모드에서 **느낌표 필수** |
| **오디션 모드만 예외** | 오디션은 상시 서사 내 용어("오디션 참가자", "오디션 라운드" 등)라 자연스러운 등장 빈도 높음 → 오히려 상시 활성이 적절 |
| **기폭제 + 유지제 키워드 공유** | 시작 로어북(1회 기폭)과 본체 로어북(매턴 유지)은 **동일한 시작 키워드**를 공유해야 `!매니저모드` 1회 입력으로 둘 다 활성됨. 유지 이모지(📋·▷ 등)는 본체에만 추가 |
| **풀네임 + 축약 병기** | `!매니저모드`(공식) + `!매니저`(축약) 양쪽 등록. 유저가 어떤 형태로 입력해도 작동 |
| **서브 이벤트·분기 로어북은 범위 밖** | `배우모드_방영`, `연습생모드_공개평가` 등 서사 내 자연어 키워드 로어북은 **변경하지 않는다** — 서사 맥락 매칭이라 `!` 불필요 |

## 1. tools/edenchat_clipboard.py 파싱 포맷 (고정)

```
// --- TRIGGER ---
// 키워드1, 키워드2, 키워드3
// 키워드4, 키워드5
```

- `// --- TRIGGER ---` 이후 모든 줄 스캔
- `// ` 제거 후 콤마 split
- 각 키워드 `Enter`로 개별 입력

**제약**: 키워드 간 구분자는 **쉼표(`,`) 고정**. 공백 허용. 여러 줄 가능.

## 4. 안전성 분석

### 오발동 가능성 검토

| 키워드 | 평가 | 근거 |
|---|---|---|
| `!매니저`, `!배우`, `!연습생`, `!작곡가`, `!인플루언서`, `!대표`, `!디테일`, `!스킵`, `!소꿉친구`, `!비하인드`, `!오디션`, `!오디션참가` | 🟢 안전 | `!` 접두사 덕에 일반 명사와 분리. AI 출력/유저 입력에 자연스럽게 나올 확률 0 |
| `오디션모드`, `오디션` (느낌표 없음) | 🟡 허용 (의도적) | 오디션 모드는 상시 활성이 서사적으로 자연스러움. 일반 서사의 "오디션" 언급에도 매칭되지만, 로어북 내용이 이미 오디션 서사 가정이라 무해 |

### 기폭제·유지제 동시 활성 동작

```
유저 입력: "!매니저모드"
   ↓
[매니저모드_시작_EN] 트리거 키워드 매칭 → 1회 기폭 (모드 세팅 지시)
[매니저모드_EN]      트리거 키워드 매칭 → 최초 활성 (본체 지침 제공)
   ↓
AI 응답 생성 (상태창에 📋 포함)
   ↓
이후 턴:
[매니저모드_시작_EN] 매칭 없음 → 1회성 종료 ✅
[매니저모드_EN]      📋 매칭 → 매턴 유지 ✅
```

**핵심**: 기폭제와 유지제가 **같은 키워드를 공유**해야 첫 호출 시 두 파일이 동시에 활성. 유지 이모지는 본체에만 있어 이후 자동으로 시작 로어북만 꺼짐.
