1. 리팩터링 요약

기존 로직은 seed mask를 edge에 맞춰 계속 확장하는 방식이라, 내부 묘사와 lineart 끊김에 지나치게 민감합니다. 반면 리팩터링 버전은 이미 검출된 세그멘테이션 마스크를 보수적으로 복원하는 방향이라 결과가 훨씬 안정적입니다.
  • 내부 핏줄·하이라이트가 경계처럼 보이더라도 flood fill로 구멍을 메웁니다.
  • 전체 이미지 대신 bbox 기반 ROI 안에서만 후처리해 주변 오검출 간섭을 줄입니다.
  • largest area만이 아니라 bbox 중심과의 거리를 같이 써서 주 객체를 고릅니다.
교체
geodesic dilation 루프

메인 엔진에서 제거하고 optional trim 단계로 내렸습니다.

추가
flood_fill_holes()

내부 구멍 제거용 전용 함수입니다.

추가
keep_best_component()

면적과 중심 거리 점수를 함께 써서 메인 성분만 남깁니다.

추가
fill_from_contour()

정제된 바이너리 마스크의 외곽을 다시 채워 결과를 단단하게 만듭니다.

기대 효과는 크게 세 가지입니다. (1) 내부 빈칸 감소, (2) 영역 밖 새어 나감 감소, (3) 튜닝 난이도 하락입니다.
내부 fill 안정화

구멍이 구조적으로 메워져 검열 품질이 더 균일해집니다.

번짐 감소

ROI와 component 선택 덕분에 주변 blob 혼입이 줄어듭니다.

예측 가능한 튜닝

blur와 edge threshold보다 morphology 파라미터가 더 직관적입니다.

2. 변경 아키텍처

Step 1

YOLO seed 확보

segmentation 마스크를 원시 seed로 사용

Step 2

BBox 기반 ROI 제한

후처리 대상 공간을 강하게 제한

Step 3

Closing + Hole Fill

끊김을 닫고 내부 구멍을 제거

Step 4

Best Component 선택

면적과 중심 거리로 주 객체 고정

Step 5

Contour/Hull 재채우기

최종 외곽을 매끈하게 봉합

추천 철학은 간단합니다. 경계를 찾으려 하지 말고, 이미 찾은 대상을 복원하라.

3. 어디를 교체할지

교체 대상 함수

  • yolo_detect(): detection별 bbox 기반 ROI와 새 refine 함수를 사용하도록 교체
  • apply_censor(): 그대로 사용 가능
  • process_single(): 그대로 사용 가능

새로 추가되는 헬퍼

  • expand_bbox()
  • flood_fill_holes()
  • keep_best_component()
  • fill_from_contour()
  • refine_segmentation_mask()

적용 순서

  1. 기존 geodesic dilation 블록을 제거합니다.
  2. 새 helper 함수들을 추가합니다.
  3. YOLO 결과마다 bbox + seg mask를 받아 refine_segmentation_mask() 를 호출합니다.
  4. 최종 정제 마스크를 OR 합성한 뒤 기존 censor 적용 로직으로 넘깁니다.

5. 튜닝 포인트

          

            

              
                

                  항목
                  권장값
                  효과
                  주의점
                

              
              
                

                  ROI pad
                  2% ~ 6%
                  seed 주변만 다뤄 주변 노이즈 차단
                  너무 작으면 진짜 외곽이 잘릴 수 있음
                

                

                  closing kernel
                  base_dim * 0.006 ~ 0.012
                  끊긴 윤곽과 작은 틈 봉합
                  크면 주변 객체와 붙을 수 있음
                

                

                  opening kernel
                  closing보다 작게
                  튀어나온 잔돌기 제거
                  과하면 본체가 깎임
                

                

                  seg threshold
                  0.40 ~ 0.55 sweep
                  seed 두께와 안정성 조절
                  너무 높으면 seed가 빈약해짐
                

                

                  hull 사용 여부
                  기본 ON
                  내부를 더 꽉 채움
                  아주 오목한 형상을 다소 넓게 덮을 수 있음
