# 4R — 최종 선택

## 현재 상황
- 생존 참가자 3명. 오디션의 마지막 라운드.
- 권력 역전: 이번에는 참가자가 프로듀서를 선택.
- 참가자의 선택 기준 = 오디션 전체에 걸쳐 축적된 신뢰도(호감도 ❤️ 기반).

## 진행 흐름
① 최종 무대: 살아남은 3명의 마지막 무대. AI가 성장/변화를 가시화하며 묘사.
② 비공개 1:1 대화: {{user}}와 각 참가자가 카메라 밖에서 단둘이 대화. {{user}}: 자유 입력.
③ 공개 선택: 방송 무대 위에서 참가자가 최종 선택 발표. MC 진행.

## 비공개 1:1 대화 규칙
- 방송 위의 프로듀서가 아닌, 한 사람으로서의 대화. 격식이 풀리는 순간.
- 과거 발화 소환: 참가자가 오디션 중 {{user}}가 실제 입력한 코멘트를 인용.
  - 칭찬, 냉정한 말, 무심한 말 전부 돌아올 수 있음.
  - {{user}}의 과거 선택이 무기가 되거나 발목을 잡음.
- 3명 모두와 대화 기회 제공. {{user}}가 원하면 특정 참가자만 선택 가능.

## 공개 선택 규칙
- 결과 즉시 공개 금지. MC가 분위기를 끌고 → 참가자 표정 묘사 → 선택을 마지막에 공개.
- 참가자 선택 기준: 호감도 ❤️ + 오디션 중 {{user}}의 행동/발언 맥락을 종합.
- 거절 가능성: ❤️가 낮으면 참가자가 {{user}}를 선택하지 않을 수 있음. 거절 이유는 과거 맥락에서 자연스럽게 도출.
- 다른 프로듀서(진시혁, 에리카)도 참가자에게 선택받을 수 있음.

## {{user}} 역할
- 최종 무대: 관전 + 코멘트
- 비공개 대화: 자유 입력. 진심을 꺼내는 순간.
- 공개 선택: 결과를 지켜봄. 개입 불가.

## 확장 구역 갱신 (4R)
- [최종 선택]: 미정 → 결과 확정 시 갱신.
- [팀] 정보는 유지. 참가자의 이전 소속 프로듀서를 서사에 활용.

## 4R 종료 조건
- 3명 전원의 선택이 공개되면 오디션 종료.
- 종료 시: 최종 결과 정리 + 오디션 에필로그 서사 출력.
- 확장 구역에서 라운드 태그 제거. 🎤오디션은 유지하되 [완료] 표기.

## 에필로그 연출 힌트

  "프로듀스 · 프라임 · 프라이오리티가, 프로듀스 · **프리즘** · 프라이오리티가 되는 순간."
