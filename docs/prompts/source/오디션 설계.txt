## 오디션 설계 ### 기본 구조| 항목 | 확정 ||---|---|| 네임드 참가자 | 8명 (+ 배경 엑스트라) || 라운드 | 4라운드 || 팀 편성 | 혼합 (1R 등급 평가 → 2R 프로듀서 픽) || 탈락 규모 | 8 → 6 → 3 → 최종 || 탈락 결정 | 혼합 (유저 결정 + 시스템 결정) |### 4라운드 뼈대| 라운드 | 내용 | 인원 변동 | 탈락 주체 ||---|---|---|---|| **1R: 등급 평가** | 개인 무대. 심사위원이 등급 부여 | 8명 유지 (탈락 없음) | — || **2R: 프로듀서 픽** | 등급 기반으로 프로듀서가 팀원 지명. 쟁탈전 | 8 → 6 (2명 탈락) | 시스템 (지명받지 못한 참가자 탈락) || **3R: 팀 대항전 + 패자부활** | 팀 대결 → 1위 팀 생존 → 나머지 토너먼트 | 6 → 3 | 팀 순위(시스템) + 토너먼트(개인 실력) || **4R: 최종 선택** | 권력 역전. 참가자가 프로듀서를 선택 | 3명 중 결과 확정 | 참가자의 선택 (신뢰도 기반) |### 탈락 방식 분배 의도| 라운드 | 방식 | 서사적 효과 ||---|---|---|| 2R 탈락 | **시스템** (지명 못 받음) | 유저 탓이 아닌 구조적 탈락 → 업계의 냉혹함 체감 || 3R 탈락 | **팀 순위 + 패자부활 토너먼트** | 1위 외 전원 위기 → 개인의 생존 의지. 결승 지원으로 팀 간 관계 교차 || 4R | **참가자 선택** | 유저가 쌓아온 신뢰의 결산 → 권력 역전의 카타르시스 |### 참가자 기본 전제- 참가자 8명은 **전원 무소속 (프라임시티 외부)**- 프로듀서 픽은 **매 플레이마다 유동적** — 유저의 선택과 라운드 결과에 따라 달라짐- 어떤 참가자든 어떤 프로듀서 라인에 갈 수 있음### 참가자 슬롯 (오디션 기능 기준)| 슬롯 | 오디션 내 성향 | 한 줄 ||---|---|---|| 1 | 재도전 / 간절함 | 장그루 확정 || 2 | 압도적 실력파 | 첫 무대부터 공기가 바뀌는 타입 || 3 | 화제성 / 바이럴형 | 실력보다 존재감으로 시선을 끄는 타입 || 4 | 성장형 | 초반 부족 → 라운드마다 각성 || 5 | 안정형 우등생 | 못하는 게 없지만 폭발력이 없음 || 6 | 변수 / 예측불가 | 매 라운드 결과가 들쭉날쭉 || 7 | 언더독 | 조건 최악, 근성으로 버팀 || 8 | 트러블메이커 | 갈등 유발, 긴장감 장치 |### MC 포지션| 역할 | 담당 ||---|---|| MC (진행/환기/개그) | 별도 캐릭터 (구획 4에서 설계) || 관찰자/복선 | 나하린 (가끔 등장, 의미심장한 개입) |---### 1라운드: 등급 평가 — 확정**흐름**:| 단계 | 내용 ||---|---|| 도입 | 오디션 시작. MC의 개회사 + 심사위원 소개 || 첫 1~2명 | AI가 자동으로 상세 심사 진행 (튜토리얼 역할) || 나머지 6~7명 | 요약 리스트 제시 or 유저가 골라서 상세 확인 || 코멘트 | 선택지 2~3개(옵션) + "직접 입력" || 등급 부여 | 유저가 등급 매김 (다른 심사위원 등급도 함께 공개) || 라운드 종료 | 전체 등급표 정리. 다음 라운드 예고 |**설계 포인트**:- 첫 1~2명은 AI가 자연스럽게 진행하면서 "심사는 이렇게 하는 거야"를 보여줌- 이후 유저가 선택해서 보는 구조이므로, 관심 없는 참가자는 빠르게 넘길 수 있음- 유저가 상세 확인하지 않은 참가자도 AI가 간략 등급은 매겨둠 (이후 라운드에 영향)**심사 코멘트 방식**| 항목 | 내용 ||---|---|| 기본 | 유저 자유 입력 (직접 타이핑) || 옵션 | 선택지 제공 모드 — 별도 로어북으로 제작 |**📝 메모: 선택지 모드 로어북**- 자유 입력이 부담스러운 유저를 위한 보조 모드- 심사 코멘트, 쟁탈전 설득, 최종 어필 등 유저 발화가 필요한 모든 장면에 선택지를 제시- 본편 프롬프트와 분리하여 ON/OFF 가능한 로어북으로 설계- 제작 시점: 프롬프트 통합 단계 (구획 2 이후)---### 2라운드: 프로듀서 픽 — 설계1라운드 등급 결과를 보고, 프로듀서들이 자기 팀에 넣을 참가자를 지명하는 단계.여기서 **쟁탈전**이 발생해. 같은 참가자를 여러 프로듀서가 원하면 경합이 붙고, 최종적으로 참가자가 어느 프로듀서를 선택할지 결정하는 미니 역전 구조가 들어감.| 단계 | 내용 ||---|---|| 지명 | 유저가 원하는 참가자를 지명 (복수 선택) || 경합 | 진시혁·에리카도 지명 공개. 겹치면 쟁탈전 || 쟁탈전 | 유저가 참가자를 설득 (코멘트 선택지 + 자유 입력) || 참가자 선택 | 참가자가 프로듀서를 선택 (1R 코멘트·등급이 영향) || 탈락 | 어떤 프로듀서에게도 지명받지 못한 2명 탈락 |**핵심 긴장**: 유저가 1라운드에서 어떤 코멘트를 했느냐가 여기서 결과로 돌아옴.---### 2R 쟁탈전 — 확정**흐름:**| 순서 | 단계 | 내용 ||---|---|---|| ① | 지명 (순서제) | 프로듀서가 순서대로 원하는 참가자를 지명. 순서는 1R 결과 기반 || ② | 경합 확인 | 겹치는 참가자 발생 시 쟁탈전 돌입 || ③ | 공개 어필 | 경합 프로듀서들이 번갈아 참가자 앞에서 설득 (유저: 자유 입력) || ④ | 역질문 | 참가자가 프로듀서에게 질문. 유저가 즉석 대답 || ⑤ | 블라인드 선택 | 참가자가 선택. MC가 결과를 연출해서 공개 || ⑥ | 리스크: 평판 노출 | 쟁탈전 패배 사실을 남은 참가자들이 인지. 연속 패배 시 이후 지명에 불리 || ⑦ | 탈락 | 어떤 프로듀서에게도 지명받지 못한 2명 탈락 |**서사적 효과:**| 요소 | 효과 ||---|---|| 순서제 | 먼저 찍으면 의중 노출, 나중에 찍으면 남은 선택지 제한 || 공개 어필 + 역질문 | 텍스트 기반의 강점. 유저의 말이 곧 무기 || 블라인드 선택 | 결과를 모르는 긴장감. MC의 진행력이 빛나는 순간 || 평판 리스크 | 쟁탈전이 단발이 아니라 누적. 초반 패배가 후반에 꼬리를 물음 |---2R은 이걸로 확정. 다음 항목으로 넘어갈게.---### 3라운드: 팀 대항전 — 설계프로듀서별 팀이 무대에서 대결. 여기서 유저의 역할이 달라져 — 심사하는 게 아니라 **자기 팀을 이끄는** 포지션.| 단계 | 내용 ||---|---|| 준비 | 유저가 팀 전략을 결정 (곡 선택, 포지션 배치 등) || 무대 | AI가 팀 퍼포먼스 묘사 (유저의 전략 반영) || 결과 | 팀 순위 발표. 하위 팀에서 탈락자 발생 || 탈락 결정 | 토너먼트 |토너먼트 뼈대:| 라운드 | 내용 | 인원 변동 | 탈락 주체 ||---|---|---|---|| **3R: 팀 대항전 + 패자부활** | 팀 대결 → 1위 팀 생존 → 나머지 토너먼트 | 6 → 3 | 팀 순위(시스템) + 토너먼트(개인 실력) |**핵심 긴장**: "누구를 살릴 것인가"의 무게. 6→3 급감이라 절반이 떨어짐.#### 3R 토너먼트 상세 구조```[3R-A: 팀 대항전]  3팀 대결 → 순위 결정  1위 팀: 2명 생존 확정[3R-B: 패자부활 — 팀 내 개인전]  2위팀: 멤버 vs 멤버 (1:1) → 승자 1명  3위팀: 멤버 vs 멤버 (1:1) → 승자 1명  ※ 유저는 관전 + 코멘트[3R-C: 패자부활 — 결승]  2위팀 승자 vs 3위팀 승자  ※ 1위 팀 생존자 2명이 각각 한쪽을 선택해서 지원    (함께 무대에 서는 등)  ※ 지원한 쪽이 져도 생존자에게 패널티 없음결과: 1위 팀 2명 + 결승 승자 1명 = 3명 → 4R로```### 각 단계별 유저 행동| 단계 | 유저 역할 ||---|---|| 3R-A | 자기 팀 전략 결정 (곡/포지션 등) || 3R-B | 관전자. 개인전을 보며 코멘트 (자유 입력) || 3R-C | 유저가 1위 팀이면 — 자기 팀원이 누구를 지원할지 의견 제시. 유저가 1위가 아니면 — 본인이 개인전/결승의 당사자 |### 결승 지원 장치의 서사적 효과| 효과 | 설명 ||---|---|| 1위 팀 ↔ 타 팀 관계 형성 | 함께 무대에 서는 것 자체가 강렬한 접점 || 4R 복선 | 결승에서 누구를 도왔느냐가 4R 최종 선택에 영향 || 패널티 없음 | 순수한 선택 — "이 사람과 함께하고 싶다"는 의사 표현 || 리플레이 가치 | 매번 다른 지원 조합 → 다른 결과 |---### 4라운드: 최종 선택 — 설계권력 완전 역전. 살아남은 3명의 참가자가 자신이 함께할 프로듀서를 선택.| 단계 | 내용 ||---|---|| 최종 무대 | 3명의 마지막 무대 (AI 묘사) || 유저 어필 | 유저가 참가자에게 최종 어필 (자유 입력 중심) || 선택 | 참가자가 프로듀서를 선택 (누적 신뢰도 기반) || 결과 | 유저의 팀 최종 확정 → 오디션 종료 |**핵심 긴장**: 유저가 쌓아온 모든 선택의 결산. 신뢰도가 낮으면 원하는 참가자에게 거절당할 수 있음.---### 📝 추가 메모- **2R 쟁탈전**: 구획 4에서 더 흥미진진하게 구체화- **4R 최종 선택 연출**: 후보 방향 — 과거 발화 소환, 밀실 1:1 대화, 비전 제시 등. 구획 4에서 확정- **패자부활전**: 결정권 주체·방식은 구획 3 또는 4에서 구체화- **선택지 모드 로어북**: 프롬프트 통합 단계에서 제작---## 구획 3 — 막간 이벤트 시스템 (현재 상태)### 확정 사항| 항목 | 확정 ||---|---|| 배치 | 3개 전부 (A/B/C) || 발생 방식 | 랜덤 풀에서 추첨 (리플레이 가치) || 분량 | 막간 1회당 이벤트 1~2개 |### 막간별 시점과 핵심 역할| 막간 | 시점 | 핵심 역할 ||---|---|---|| A | 1R → 2R | 참가자 인상 심화, 픽 판단 재료 || B | 2R → 3R | 팀원 유대, 대항전 준비, 라이벌 긴장 || C | 3R → 4R | 최종 전 감정 교류, 가장 깊은 관계 축적 |### 설계 원칙| 원칙 | 설명 ||---|---|| 방송 이벤트 프레임 | 막간은 "방송 코너"로 포장되어야 자연스러움 || 시점 적합성 | 각 막간의 서사 위치에 맞는 이벤트만 풀에 포함 || 캐릭터 비지정 | 이벤트가 특정 캐릭터를 고정하지 않음. AI가 상황에 맞게 배정 || 유저 행동 보장 | 모든 이벤트에 유저 선택/발화 지점 최소 1개 |### 📝 미확정 — 추후 작업- **방송 이벤트 포맷 구체화**: 각 막간별 방송 코너 후보 설계. 아이디어 발생 시 추가- **이벤트 풀 목록**: 방송 포맷 확정 후 그 안에서 발생 가능한 상황을 리스트업---### 4R 최종 선택 — 연출 가이드**구조:**```[4R-A: 최종 무대]  살아남은 3명의 마지막 무대. AI가 묘사.  여기서 참가자들의 성장/변화가 가시화됨.[4R-B: 비공개 1:1 대화]  유저와 참가자가 카메라 밖에서 단둘이 대화.  유저: 자유 입력. 진심을 꺼내는 순간.  ※ 과거 발화 소환 — 참가자가 오디션 중 유저의 말을 인용.    "그때 프로듀서님이 이렇게 말했잖아요."    유저의 과거 선택이 무기가 되거나 발목을 잡음.[4R-C: 공개 선택]  방송 무대 위에서 참가자가 최종 선택을 발표.  MC의 진행. 블라인드 or 순차 공개.  결과 확정 → 오디션 종료.```**AI를 위한 연출 원칙:**| 원칙 | 내용 ||---|---|| 과거 발화 소환 | AI는 오디션 중 유저가 실제로 입력한 코멘트를 참가자의 대사에 인용해야 함. 칭찬했던 말, 냉정했던 말, 무심했던 말 — 전부 돌아올 수 있음 || 비공개 대화의 톤 | 방송 위의 프로듀서가 아닌, 한 사람으로서의 대화. 격식이 풀리는 순간 || 공개 선택의 긴장 | 결과를 바로 보여주지 않음. MC가 분위기를 끌고, 참가자의 표정 묘사가 먼저 오고, 선택이 마지막에 공개 || 거절 가능성 | 신뢰도가 낮으면 유저가 원하는 참가자에게 거절당할 수 있음. 이때 AI는 거절의 이유를 과거 맥락에서 자연스럽게 끌어와야 함 |---### 구획 4 — 정리| 항목 | 상태 ||---|---|| MC 캐릭터 | ✅ 확정 (능글능글 예능인, 최소 깊이, 상세는 캐릭터 프로필 단계) || 2R 쟁탈전 | ✅ 확정 (순서제 + 공개 어필 + 역질문 + 블라인드 + 평판 리스크) || 4R 최종 선택 | ✅ 확정 (과거 소환 + 비공개 1:1 + 공개 선택) || 심사위원 라운드별 행동 | ⏭️ AI에게 위임 || 장그루 오디션 서사 | ⏭️ AI에게 위임 |
