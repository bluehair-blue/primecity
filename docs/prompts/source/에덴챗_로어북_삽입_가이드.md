# 에덴챗 로어북 삽입 가이드
## Claude Chrome Extension 사용 프롬프트

아래 프롬프트를 에덴챗 편집 페이지(`/edit-work/...`)가 열린 상태에서 Claude Chrome에 붙여넣으세요.

---

### 프롬프트

```
이 페이지는 에덴챗(EdenChat) 챗봇 편집 화면입니다. 아래 JSON 파일들의 내용을 로어북(Lorebook)에 삽입해야 합니다.

## 작업 개요

총 6개의 JSON 파일을 에덴챗의 로어북 시스템에 입력합니다:

### 1. 메인 프롬프트 (상시 로딩)
- 파일: 연예계_메인_프롬프트_EN.json
- 위치: 시스템 프롬프트 또는 상시 활성 로어북
- 특징: 모든 대화에서 항상 활성화

### 2. 캐릭터 로어북 (트리거 기반)
- 파일: 연예계_로어북_캐릭터_EN.json
- 배열 내 각 객체 = 1개 로어북 엔트리
- 트리거: 각 객체의 "trigger" 필드 (예: "진시혁", "에리카")
- 특징: 해당 캐릭터 이름이 최근 대화에 등장할 때만 활성화
- 총 14개 엔트리 (서윤~라피스)

### 3. 오디션 로어북 (트리거 기반)
- 파일: 연예계_로어북_오디션_EN.json
- 배열 내 각 객체 = 1개 엔트리
- 트리거: "!오디션모드", "🎙️1", "🤝2", "🏠0", "⚔️3", "🥊3", "🏆3", "👑4"
- 특징: 오디션 모드 활성화 시 해당 라운드 로어북만 로딩
- 총 8개 엔트리

### 4. 나하린 로어북 (트리거 기반, 🔒스포일러)
- 파일: 연예계_로어북_나하린_EN.json
- 단일 객체 = 1개 엔트리
- 트리거: "나하린"
- 특징: 나하린 관련 대화에서만 활성화. 스포일러 보호.

### 5. 세계관 이면 로어북 (트리거 기반, 🔒스포일러)
- 파일: 연예계_로어북_세계관이면_EN.json
- 단일 객체 = 1개 엔트리
- 트리거: "🌑세계관"
- 특징: 나하린 Layer 2+ 진입 후에만 활성화

### 6. 모드 로어북 (트리거 기반)
- 파일: 연예계_로어북_모드_EN.json
- 배열 내 각 객체 = 1개 엔트리
- 트리거: "!매니저모드", "!연습생모드", "!작곡가모드", "!배우모드", "!인플루언서모드", "시작/오프닝/첫 대화", "!선택지"
- 총 7개 엔트리

## 삽입 규칙

1. **메인 프롬프트**: "시스템 프롬프트" 또는 "항상 활성" 영역에 전체 JSON을 입력
2. **로어북 엔트리**: 각 JSON 배열 원소를 개별 로어북 항목으로 생성
   - "키워드/트리거" 필드에 trigger 값 입력
   - "내용" 필드에 해당 객체 전체를 JSON 형태로 입력
3. **활성화 조건**: "키워드가 최근 N턴 내 등장 시 활성화" 방식
4. **우선순위**: 메인 프롬프트 > 캐릭터 > 오디션/모드 > 나하린/세계관이면

## 현재 페이지에서 확인해야 할 것

1. 로어북/월드인포 입력 UI가 어디에 있는지 확인
2. 시스템 프롬프트 입력란이 어디에 있는지 확인
3. 트리거 키워드 설정 방법 확인
4. 각 로어북 엔트리의 최대 글자 수 제한 확인
5. 동시 활성화 가능 엔트리 수 제한 확인

페이지의 UI 구조를 분석하고, 위 파일들을 어떤 순서로 어디에 입력해야 하는지 단계별 계획을 세워주세요.
```
