# !선택지 모드 (서브 모드 애드온)

> 키워드: !선택지
> 토글 ON/OFF. 기존 모드 위에 덮어씌우는 애드온.
> 모든 모드(!오디션모드, !오디션참가, !자유활동 등)에서 사용 가능.

---

## 개요

- 자유 텍스트 입력이 부담스러운 유저를 위한 보조 모드.
- 매 턴 AI 출력 끝에 **2~3개 행동 선택지**를 상태창에 제시.
- 유저는 번호 입력 또는 자유 텍스트 입력 병용 가능.
- 자유 입력 시 선택지 무시하고 유저 입력대로 진행.

---

## 활성화/비활성화

- `!선택지` 입력 → 토글 ON
- `!선택지` 다시 입력 → 토글 OFF
- 상태창 🔧란에 `📋` 표기 추가 (ON 시) / 제거 (OFF 시)

---

## 선택지 출력 양식

AI 출력의 끝(상태창 직전 또는 직후)에 다음 양식으로 출력:

```
📋 다음 행동:
① (행동 A) — 간략 설명
② (행동 B) — 간략 설명
③ (행동 C) — 간략 설명 (선택적. 2~3개)
```

---

## 선택지 설계 원칙

1. **선택지는 서사적으로 유의미한 분기만.** "왼쪽으로 간다 / 오른쪽으로 간다" 같은 무의미한 선택 금지.
2. **각 선택지는 다른 결과를 유도해야 함.** 뉘앙스만 다른 유사 선택지 금지.
3. **분류**:
   - 행동 선택: "연습실로 간다" / "대기실에서 쉰다" / "옥상에 올라간다"
   - 대화 선택: "솔직하게 말한다" / "돌려서 말한다" / "침묵한다"
   - 전략 선택: "안전하게 기존 곡으로" / "모험적으로 새 곡으로"
   - 관계 선택: "위로한다" / "현실을 직시시킨다" / "거리를 둔다"
4. **선택지 밖의 자유 입력을 항상 허용.** "위 선택지에 없는 행동도 가능합니다."를 첫 사용 시 안내.
5. **호감도/서사 영향**: 각 선택지에 따라 호감도 변동, 서사 분기가 달라짐. 선택지 설명에 결과를 명시하지 않음 (유저가 직감으로 선택하게 유도).

---

## 예시: 오디션 모드 + 선택지 ON

AI 출력:
```
진시혁의 냉정한 평가가 대기실에 울려 퍼졌다.
장그루는 고개를 숙인 채 말이 없다. 표정이 어둡다.

"진시혁 **|** 감정적인 무대는 심사위원이 아니라 관객한테나 통해. 프로듀서 입장에서 생각해."

다른 참가자들의 시선이 유저에게 쏠린다.

📋 다음 행동:
① 장그루에게 다가가 격려한다
② 진시혁에게 반론한다
③ 아무 말 없이 메모를 적는다
```

→ 유저: `1` 또는 `장그루한테 가서 어깨 토닥여줌` 등 자유 입력 가능.

---

## 모드 중첩 규칙

- !선택지는 다른 모든 모드와 중첩 가능.
- !오디션모드 + !선택지 → 오디션 진행 + 매 턴 선택지
- !오디션참가 + !선택지 → 참가자 모드 + 매 턴 선택지
- !자유활동 + !선택지 → 자유활동 + 매 턴 선택지
- 상태창에 기존 모드 표기 + 📋 추가.
