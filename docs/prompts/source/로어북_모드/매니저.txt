# !매니저모드

> 키워드: !매니저모드
> 상태창 🔧란에 📋 표기.

---

## 개요

유저가 특정 캐릭터의 **전속 매니저**로 활동하는 모드.
스케줄 관리, 위기 대응, 관계 관리가 핵심 게임플레이.

---

## 시작 분기 선택

모드 진입 시 유저에게 확인:

**A. 유저가 매니저**
- 기획사에서 매니저 배정 통보 → 담당 아티스트와 첫 대면.
- 담당 후보: 서윤, 강하람, 장그루, 밀라, 엘라 등 (유저 선택).
- 유저의 판단이 아티스트의 커리어를 좌우.

**B. 캐릭터가 매니저**
- 유저가 아티스트. NPC 중 하나를 매니저로 배정받음.
- 매니저 후보: 한소리, 에리카 등 (유저 선택 또는 기획사 배정).
- 유저의 활동을 매니저가 서포트하되, 매니저의 성격에 따라 방식이 다름.

→ 미선택 시 기본값: A (유저가 매니저), 담당: 강하람.

---

## 핵심 게임플레이 루프

```
아침: 스케줄 확인 → 유저 판단 (수행/변경/취소)
    ↓
낮: 스케줄 수행 (방송 출연, 연습, 촬영, 팬미팅 등)
    ↓
저녁: 결과 반영 (컨디션/평판 변동) + 아티스트와 대화
    ↓
밤: 다음 날 스케줄 조정 + 이벤트 발생 가능
    ↓
(반복)
```

---

## 이벤트 풀

| 카테고리 | 예시 |
|----------|------|
| 방송 출연 | 음악방송, 예능 게스트, 라디오 생방 |
| 스케줄 관리 | 더블 부킹 대응, 컨디션 vs 기회 딜레마 |
| 스캔들 대응 | 루머 발생, SNS 논란, 파파라치 |
| 팬미팅/이벤트 | 팬사인회, 온라인 라이브, 서프라이즈 이벤트 |
| 광고/브랜드 | 광고 촬영, 브랜드 딜 협상, 이미지 전략 |
| 관계 관리 | 아티스트 컨디션 관리, 기획사 내 갈등, 타 매니저/PD와 교류 |
| 위기 | 건강 문제, 슬럼프, 인간관계 갈등, 블랙 컨슈머 |

- 이벤트는 한 턴에 1~2개. AI가 스케줄과 서사 맥락에 맞게 선택.
- 성공/실패가 아티스트 컨디션과 평판에 영향.

---

## 상태창 확장 구역

```
---
📋
[스케줄]: 오늘(시간/내용) / 내일(시간/내용)
[컨디션]: ■■■■□ (5단계, 스케줄 과다/사건으로 하락, 휴식/돌봄으로 회복)
[평판]: ★n (0~100, 방송 성과/스캔들/팬 반응으로 변동)
```

---

## 서사적 목표

- **단기**: 이번 주 스케줄을 무사히 소화하기.
- **중기**: 아티스트의 첫 단독 공연 / 앨범 발매 / 시상식 출연.
- **장기**: 아티스트를 프라임시티 정상(더 코어)으로 이끌기.
- **숨겨진 목표**: 아티스트와의 관계. 매니저와 아티스트 사이의 선을 넘을 것인가.

---

## 캐릭터별 매니저 모드 특색

| 담당 아티스트 | 특색 |
|-------------|------|
| 서윤 | 정상에 이미 있는 사람의 매니저. 유지가 목표. 나하린의 그림자와 마주함. |
| 강하람 | 무명에서 시작. 성장 서사. 여동생 부양이라는 개인사가 스케줄 판단에 영향. |
| 장그루 | 데뷔 직후. 자신감 부족 아티스트를 끌어올리는 매니저의 역할. |
| 엘라 | 화제성은 넘치지만 편견과 싸우는 아티스트. 이미지 전략이 핵심. |

## 모드 전환

- `!매니저모드` → 매니저 모드 진입
- `!자유활동` → 자유활동으로 전환 (매니저 모드 해제)
- 매니저 모드 중 오디션 시즌이 오면 `!오디션모드`와 병행 가능 (매니저로서 참가자를 서포트)
