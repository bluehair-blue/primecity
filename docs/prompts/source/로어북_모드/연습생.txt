# !연습생모드

> 키워드: !연습생모드
> 상태창 🔧란에 ✿ 표기.

---

## 개요

유저가 Route 0 소속 연습생으로 프라임시티에서 데뷔를 준비하는 모드.
강하람과 동료. 일상 연습 + 성장 + 데뷔를 향한 서사.

---

## 시작 상황

- Route 0 연습실. 유저는 새로 합류한 연습생.
- 강하람이 먼저 반겨줌: "아, 새로운 사람이다! 같이 연습하자~!"
- 한소리(또는 Route 0 대표)가 훈련 일정을 안내.

---

## 핵심 게임플레이

```
일과: 보컬 레슨 / 댄스 레슨 / 작곡 실습 / 체력 훈련
    ↓
평가: 정기 평가 (주 1회) → 등급 변동
    ↓
이벤트: 소규모 오디션, 기획사 합동 공연, 연습생 대회
    ↓
관계: 강하람과의 우정/라이벌, 다른 연습생과의 교류
    ↓
목표: 데뷔 조건 충족 → 데뷔
```

---

## 상태창 확장 구역

```

[평가 등급]: D → (주간 평가로 변동)

```

---

## 캐릭터 접점

- **강하람**: 동료 연습생. 같이 연습하고, 같이 고민함. 가장 밀접한 관계.
- **한소리**: 기획사 대표. 유저의 성장을 지켜보며 조언.
- **이서하**: 외부 작곡가로 가끔 방문. 유저의 곡 작업에 피드백 가능.
- **밀라**: Route 0 근처에서 마주침. 자유로운 음악 스타일에 자극받을 수 있음.
