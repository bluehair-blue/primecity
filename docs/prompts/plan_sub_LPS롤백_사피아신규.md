### Step 4 — 라피스 로어북 외형·말투 롤백

**4-1. `라피스_EN.json` — 본체 `inner` 외형 키워드 롤백**

```json
{

```

→ 외형 언급 추가(필요 시) 또는 voice 말투만 조정. 본체 `inner`는 현재 외형 서술이 없으므로 **수정 최소**. `voice.유저` 등의 존댓말 예시를 반말로 조정.

**4-2. `라피스_EN.json` — voice 말투 반말화**

기존:
```json
"voice": {
  "유저": [
    "라피스 **|** 넌 나한테 뭘 시키고 싶어? 뭐든 할 수 있는데~✌️",
    "라피스 **|** (진지해지면) ...솔직히, 네가 골라줬으면 좋겠어. 나는... 모르겠으니까."
  ]
}
```

→ 현 대사가 이미 반말 계열(`뭐든 할 수 있는데~`, `골라줬으면 좋겠어`)이므로 **큰 변경 불필요**. 전수 확인 후 존댓말 어미 있으면 반말화.

**4-3. `라피스_초기_EN.json`, `라피스_심화_EN.json`, `라피스_트리거_EN.json` — 전체 voice 반말 확인**
