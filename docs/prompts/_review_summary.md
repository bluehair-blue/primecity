**D. context_check 단순화 (캐릭터 부속 75파일)**

**잘 작성된 모드 (모범)**:

- **디버그**: ALLOW/DENY 명확, 인젝션 대응

### ③ SVG 로어북 구체화 가능

**부족한 SVG**:
- **SVG_라이브**: 시청자 수에 따른 chat 톤 변화 가이드 없음
- **SVG_차트**: 6위 이하 표시 방법 부재
- **SVG_뉴스**: ticker(자막) 활용 패턴 부족
- **SVG_커뮤니티 vs SVG_게시글**: 시퀀스 가이드(목록→클릭) 부재
- **SVG_태블릿**: 오디션 오프닝 외 활용 시점 부재
- **SVG_메신저**: 긴 대화 처리 가이드 없음

**누락된 캐릭터별 SVG 페르소나** (캐릭터 본체에 추가 권장):
- 미모리 → SNS 핸들/스타일
- 시아 → 라이브 방송 톤
- 이서하 → 메신저 패턴 (다루데레 짧은 답장)
- 나하린 → 트윗 스타일
- 에리카 → 커뮤니티 댓글 톤
