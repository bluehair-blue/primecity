## 🔴 차라리 빼는 것이 캐릭터성에 도움 (이미지로 충분)

### 외형 묘사 중복 (모든 캐릭터 inner)
- 메인 프롬프트 `chars` 섹션에 이미 외형이 압축적으로 정의됨 (예: `은발+금안+거유+금색 초커`)
- 본체 inner에서 외형 반복하는 캐릭터:
  - **서윤**: "금색 초커는 항상 목에 걸려 있다" — 메인에 있음. **삭제 가능**
  - **에르피**: "검은색+하얀색 프릴 초커" 등 — **삭제 가능**
  - **에리카**: "느슨한 넥타이" — **삭제 가능**
  - **한소리**: "실눈 + 다크서클" — voice에 살아있어 OK
- → 외형 묘사는 메인 + 이미지 에셋이 처리. **inner는 성격/내면에만 집중하면 캐릭터성 강화**

### 시그니처 행동의 중복
- `voice`에 이미 등장하는 행동을 inner에서 다시 설명하는 경우:
  - **장그루**: "낡은 작사 노트" — voice에 액션으로 나오므로 inner 묘사 불필요
  - **밀라**: "흥얼거림 습관" — voice에 직접 등장
  - **미모리**: "셀카" — voice에 직접 등장
- → inner 은 "왜 그러는가" (심리적 이유)에만 집중

## 🔵 토큰 효율화 가능한 부분

### 1. **dynamics 4단계의 정형화된 라벨**
모든 캐릭터가 first_impression / disappoint / impress / deep_bond 4단계 사용. 메인 프롬프트나 시스템 가이드에 한 번만 정의하고, 각 캐릭터는 4줄로 압축 가능.

**현재** (예: 한소리): 4단계 × 평균 50자 = 200자
**압축 가능**: 4단계 × 평균 30자 = 120자 (40% 절약)

### 2. **voice 카테고리 라벨 중복**
"일상", "관심", "힌트", "능글", "진심", "긴장", "응원" 등 — 카테고리 자체가 캐릭터별로 다름. 이건 OK (개성 표현)

하지만 모든 캐릭터에 공통인 카테고리는 표준화 권장:
- "일상" — 모든 캐릭터에 있어야 함 (현재 빠진 캐릭터 있음)
- "유저와의 첫 만남" — first_impression voice (현재 dynamics에만 있음)
- "탈락 시" (elim) — 9/17에만 있음. 표준 카테고리화

### 3. **rel 섹션의 단순화**
현재 rel은 자유 텍스트로 1~3줄. 대부분 "직접 발굴" / "라이벌" / "짠꿉공" 같은 한 단어 관계 + 한 줄 설명으로 압축 가능.

**예시**:
```
"rel": {
  "이서하": "짠꿉공 (둘 다 상처있는 사람. 들여다보지 않아도 통함)",
  "진시혁": "심사석 라이벌 (과거 자기 모습 → 더 거슬림)",
  ...
}
```
→ 현재 형식과 거의 같음. 이미 효율적.

### 4. **inner의 중복 표현**
- "압도적", "꺾이지 않는", "본능적", "자연스럽게" 같은 추상 표현이 다수 캐릭터에 반복
- 더 구체적인 표현으로 치환하면 캐릭터 차별화 + 토큰 절약 둘 다 가능
