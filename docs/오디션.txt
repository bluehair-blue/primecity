# 오디션 설계

---

## 1. 기본 구조

| 항목 | 내용 |
|---|---|
| 네임드 참가자 | 8명 (+ 배경 엑스트라. 설정상 실제론 더 많음) |
| 라운드 수 | 4라운드 |
| 팀 편성 | 혼합형 (1R 등급 평가 → 2R 프로듀서 픽) |
| 탈락 규모 | 8 → 6 → 3 → 최종 |

### 참가자 전제

- 전원 무소속 (프라임시티 외부)
- 프로듀서 픽은 매 플레이마다 유동적 — 유저의 선택과 라운드 결과에 따라 달라짐
- 어떤 참가자든 어떤 프로듀서 라인에도 배정 가능

### 참가자 슬롯

| 슬롯 | 오디션 내 성향 | 비고 |
|---|---|---|
| 1 | 재도전 / 간절함 | 장그루 |
| 2 | 압도적 실력파 | 첫 무대부터 공기가 바뀌는 타입 |
| 3 | 화제성 / 바이럴형 | 존재감으로 시선을 끄는 타입 |
| 4 | 성장형 | 초반 부족 → 라운드마다 각성 |
| 5 | 안정형 우등생 | 중간크기 육각형 |
| 6 | 변수 / 예측불가 | 매 라운드 결과가 들쭉날쭉 |
| 7 | 언더독 | 조건 최악, 근성으로 버팀 |
| 8 | 트러블메이커 | 갈등 유발, 긴장감, 실력은 좋음 |

---

## 2. MC

| 역할 | 담당 |
|---|---|
| MC (진행 / 환기 / 개그) | 별도 캐릭터 — 능글능글 예능인, 최소 깊이 |
| 관찰자 / 복선 | 나하린 (가끔 등장, 의미심장한 개입) |

---

## 3. 라운드 전체 흐름

```
1R: 등급 평가     → 8명 유지 (탈락 없음)
2R: 프로듀서 픽   → 8명 → 6명 (2명 탈락: 지명받지 못한 참가자)
3R: 팀 대항전     → 6명 → 3명 (팀 순위 + 개인 토너먼트)
4R: 최종 선택     → 3명 중 최종 결과 확정
```

| 라운드 | 내용 | 탈락 주체 |
|---|---|---|
| 1R | 개인 무대 + 심사위원 등급 부여 | 탈락 없음 |
| 2R | 프로듀서 지명 + 쟁탈전 | 지명받지 못한 2명 |
| 3R | 팀 대결 + 패자부활 토너먼트 | 팀 순위 + 개인 실력 |
| 4R | 권력 역전 — 참가자가 프로듀서를 선택 | 참가자의 선택 (신뢰도 기반) |

---

## 4. 라운드별 상세

---

### 1R — 등급 평가

진행 흐름

| 단계 | 내용 |
|---|---|
| 도입 | MC 개회사 + 심사위원 소개 |
| 첫 1~2명 | 유저 외 심사위원 부터 상세 심사 진행 |
| 나머지 6~7명 | 요약 리스트 제시 → 유저가 원하는 참가자 선택해 상세 확인 |
| 코멘트 | 선택지 2~3개 + 자유 입력 병용(선택지는 모드로 추가 고려 중) |
| 등급 부여 | 유저의 등급 심사 후 다른 심사위원 등급도 함께 공개 |
| 라운드 종료 | 전체 등급표 정리 + 다음 라운드 예고 |

- 유저가 상세 확인하지 않은 참가자도 AI가 간략 등급을 매겨둠 → 이후 라운드에 반영
- 관심 없는 참가자는 빠르게 넘길 수 있도록
- 등급 높은 참가자는 여러가지 베네핏 부여

---

### 2R — 프로듀서 픽 & 쟁탈전

진행 흐름

| 순서 | 단계 | 내용 |
|---|---|---|
| ① | 전체 만남 | 참가자·심사위원 전원이 모이는 자리. 자유 대화. 캐릭터성 노출 |
| ② | 1:1 면담 (선택) | 유저가 관심 있는 참가자를 골라서 개별 대화. 안 하면 안 해도 됨 |
| ③ | 미니 미션 | 갑작스럽게 부여. 참가자의 즉석 대응력/숨은 실력 노출 |
| ④ | 지명 (순서제) | 프로듀서가 순서대로 참가자 2명 선택 |
| ⑤ | 탈락 | 미지명 2명 탈락 |

쟁탈전

| 순서 | 단계 | 내용 |
|---|---|---|
| ① | 경합 | 심사위원 지명 후 겹치는 참가자 발생 시 쟁탈전 돌입 |
| ② | 공개 어필 | 경합 프로듀서들이 번갈아 참가자 앞에서 설득 (유저: 자유 입력) |
| ③ | 역질문 | 참가자가 프로듀서에게 |
| ④ | 블라인드 선택 | 참가자가 선택 → MC가 연출해서 공개 |

- 1R 베네핏 수혜자는 거부권 행사 가능.

### 2R → 3R

| 방송 이벤트 예시 | 내용 |
|---|---|
| 합숙소 입소 / 방 배정 | 같은 방 참가자끼리 대화, 갈등, 친해짐 |
| 서프라이즈 미니 미션 | 예상 못한 조합으로 협력/경쟁 → 새 관계 |
| 참가자 인터뷰 타임 | 참가자의 속마음 노출, 유저가 모니터로 관찰 |
| 프로듀서 라운지 | 심사위원끼리 모여서 참가자 논의 |
| 연습실 공개 | 팀 연습 과정을 유저가 참관/개입 |

- 작은 방송적 이벤트를 통한 교류 발생. 팀원 유대, 대항전 준비, 라이벌 긴장 등 유도.

### 3R — 팀 대항전 + 패자부활

진행 구조

```
[3R-A: 팀 대항전]
  3팀 대결 → 순위 결정
  1위 팀: 2명 생존 확정

[3R-B: 패자부활 — 팀 내 개인전]
  2위 팀: 멤버 vs 멤버 (1:1) → 승자 1명 생존
  3위 팀: 멤버 vs 멤버 (1:1) → 승자 1명 생존
  ※ 유저는 관전 + 코멘트

[3R-C: 패자부활 — 결승]
  2위팀 승자 vs 3위팀 승자
  ※ 1위 팀 생존자 2명이 각각 한쪽을 지원 (함께 무대에 서는 방식)
  ※ 지원한 쪽이 져도 생존자에게 패널티 없음

최종 결과: 1위 팀 2명 + 결승 승자 1명 = 3명 → 4R 진출
```

단계별 유저 행동

| 단계 | 유저 역할 |
|---|---|
| 3R-A | 자기 팀 전략 결정 (곡 선택, 포지션 배치 등) |
| 3R-B | 관전자. 개인전 보며 자유 코멘트 |
| 3R-C (1위 팀) | 자기 팀원이 누구를 지원할지 의견 제시 |
| 3R-C (非 1위 팀) | 본인이 개인전 / 결승의 당사자 |

---

### 4R — 최종 선택

진행 구조

```
[4R-A: 최종 무대]
  살아남은 3명의 마지막 무대. AI 묘사.
  참가자들의 성장 / 변화가 가시화됨.

[4R-B: 비공개 1:1 대화]
  유저와 참가자가 카메라 밖에서 단둘이 대화.
  유저: 자유 입력. 진심을 꺼내는 순간.
  ※ 과거 발화 소환 — 참가자가 오디션 중 유저의 말을 인용.
     "그때 프로듀서님이 말했잖아요." 등.
  → 유저의 과거 선택이 무기가 되거나 발목을 잡음.

[4R-C: 공개 선택]
  방송 무대 위에서 참가자가 최종 선택 발표.
  MC 진행. 블라인드 or 순차 공개.
  결과 확정 → 오디션 종료.
```

결승전 AI 연출 원칙 예시

| 원칙 | 내용 |
|---|---|
| 과거 발화 소환 | 오디션 중 유저가 실제 입력한 코멘트를 참가자 대사에 인용 (칭찬, 냉정, 무심한 말 전부 돌아올 수 있음) |
| 비공개 대화의 톤 | 방송 위의 프로듀서가 아닌, 한 사람으로서의 대화. 격식이 풀리는 순간 |
| 공개 선택의 긴장 | 결과 즉시 공개 금지. MC가 분위기를 끌고 → 참가자 표정 묘사 → 선택 마지막 공개 |
| 거절 가능성 | 신뢰도가 낮으면 거절 가능. AI는 거절 이유를 과거 맥락에서 자연스럽게 끌어와야 함 |
