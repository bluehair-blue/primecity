# Decision Record Template

> 채택·기각·보류 결정을 기록할 때 사용하는 템플릿. DECISION_LOG.md에 항목 추가 시 사용.

---

## [DEC-NN] 결정 제목

**날짜**:  
**결정 유형**: 채택 (ACCEPTED) / 기각 (REJECTED) / 보류 (DEFERRED)  
**관련 이슈**: [AGENT-NN], [AGENT-NN], ...

### 결정 내용

_무엇을 하기로 / 하지 않기로 / 미루기로 했는가?_

### 근거

_왜 이 결정을 내렸는가? 트레이드오프 포함._

### 대안 검토

_다른 옵션이 있었다면 왜 선택하지 않았는가?_

### 실행 조건 (보류의 경우)

_언제, 어떤 조건이 충족되면 재검토할 것인가?_

### 담당

_누가 실행하는가?_

### 완료 기준

_어떻게 완료 여부를 확인하는가?_
